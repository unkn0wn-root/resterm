# Interface

Resterm keeps files and requests on the left, the request editor in the middle, and responses on the right.

- `Tab` / `Shift+Tab` move focus.
- `g r`, `g i`, `g p` focus navigator, editor, or response.
- `g z` zooms the focused pane and `g Z` restores the layout.
- `g 1`, `g 2`, `g 3` minimize single panes.
- `?` opens the searchable help index.

Related: `:help commands`, `:help history`.
